# CNPM-20 - Data Dictionary

## 1. Conventions

This dictionary describes the schema created by `src/main/resources/db/migration/V1__create_core_schema.sql`.

- **PK**: primary key; **FK**: foreign key; **UK**: unique constraint.
- `BIGINT AUTO_INCREMENT` identifiers are generated by MySQL.
- `TIMESTAMP(6)` stores microsecond precision. Application/JPA time is normalized to UTC.
- `created_at` and `updated_at` are audit timestamps; `updated_at` is refreshed by MySQL where declared.
- Enum-like `VARCHAR` columns are constrained by application validation until database check constraints are introduced.
- Flyway migrations are authoritative. Never edit an applied migration; add a new version.
